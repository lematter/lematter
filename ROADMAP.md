# Roadmap

This document outlines the planned direction for Lematter. It is a living
document and priorities may shift.

## Now

- [x] Set up internationalization with locale-based routing.
- [x] Establish shared app layout (header, footer).
- [x] Scaffold home page sections (hero, features, faqs, cta).
- [x] Add legal pages (terms, privacy, cookies).
- [ ] Flesh out home section content.

## Next

- [ ] Add a locale switcher in the header.
- [ ] Add a second locale to validate the i18n setup end to end.
- [ ] Build out FAQ content with an accordion component.
- [ ] Introduce a theme (light/dark) toggle.

## Later

- [ ] SEO improvements: sitemap, robots, per-locale metadata.
- [ ] Analytics integration.
- [ ] Automated testing setup (unit and end-to-end).
- [ ] CI pipeline for lint, build, and tests.

## Ideas / under consideration

- Content management for legal pages.
- Additional marketing sections (pricing, testimonials).

Have a suggestion? Open an issue to discuss it.
